## مهم بخصوص الأمان
هذه النسخة Front-end فقط. لا يوجد فيها خادم أو قاعدة بيانات أو مصادقة حقيقية أو بوابة دفع حقيقية.
لذلك لا ينبغي اعتبار localStorage أو sessionStorage أو كود الغرفة وسيلة حماية.

النسخة الحالية مناسبة لتجربة منطق الألعاب والواجهة، ومنها وضع تمرير جوال واحد بين اللاعبين للأدوار السرية.
لتحويلها إلى لعب حقيقي بين أجهزة مختلفة نحتاج Backend + قاعدة بيانات + Realtime + مصادقة، ويفضل Supabase أو خدمة مماثلة.

تم تجنب eval/Function، ويتم تعقيم النصوص المدخلة قبل إدخالها في HTML، وتوليد أكواد الغرف باستخدام crypto عند توفره.
